# Changelog

## 1.3.0 (2026-11-06)

- Snippets are typed by Hyprland instead of wtype, so they appear almost
  instantly. Fixes repeated letters with fcitx5.
- Custom date/time formats, e.g. `{date:yyMMdd}` or `{time:HH:mm:ss}`.
  See the README for details and Espanso equivalents.
- Notifications no longer interrupt a trigger you're typing.
- Quiet retry if expansion fails to start after login or sleep.

Note: literal text like `{date:yy}` in a snippet is now replaced with the date.

## 1.2.0 (2026-10-19)
